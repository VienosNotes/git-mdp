# フェーズ 5：実文書での受け入れと初版の仕上げ

## 実施したこと

### 導入手順

- `package.json` に `bin`（`git-md-diff` → `dist/src/cli.js`）を追加した。
- `npm install -g .` で npm のグローバル bin ディレクトリに `git-md-diff` が置かれ、`git md-diff` として呼び出せることを確認した（Linux、一時的なインストール先で確認）。
- グローバルインストールはクローンしたディレクトリへのリンクになり、Node はリンクの実体を基準にモジュールを解決するため、`assets/` の CSS・JS を読み込める。
- `git md-diff --help` は Git が `git help md-diff`（マニュアルページの表示）として扱うため、本ツールには届かない。使い方の表示には `-h` を使うよう README に記載した。

### 利用手順

[README.md](../README.md) に、導入、比較対象の意味、出力例、CSS の指定、一時ファイルが残ること、画面の見方、既知の制限を記載した。

### 大きな文書での性能

合成した文書（約 7,000 行、200 節、段落・表・リストを含む）の約 3% の行を変更し、236 hunks の差分で測った。Chromium（作業用コンテナ）での計測。

| 項目 | 改善前 | 改善後 |
|---|---|---|
| CLI の生成（HTML 約 1.8MB） | 0.4 秒 | 0.4 秒 |
| HTML を開いてマークが揃うまで | 約 2.0 秒 | 約 0.4 秒 |
| 表示モードの切り替え | 約 1.1 秒 | 約 0.4 秒 |
| 変更行の独立表示の切り替え | 約 1.1 秒 | 約 0.7 秒 |
| 画面幅の変更 | 約 0.6 秒 | 約 0.1 秒 |

- 差分マークの配置で、hunk ごとに文書内の全要素を検索し直していたため、候補の要素を一度だけ集めるようにした。
- 残る切り替え時間の大半は、ブラウザが切り替え先の本文をレイアウトし直す時間で、4 通りの本文を切り替える方式に伴うもの。この規模で日常利用を妨げる待ち時間ではないと判断し、これ以上の改善は行わない。

## 利用者による確認が必要なこと

フェーズ 5 のゲートのうち、次は実際の利用環境と文書で確認する。

- 実際に想定する規模の文書と複数ファイルの変更で、生成から閲覧まで一通り使い、文書のおおよその行数・hunk 数・生成時間・操作感を記録する。
- 実際の既定ブラウザの起動（フェーズ 4 からの残り。macOS を想定）。
- diff ポップアップがマークの右に開き、対応する本文の変更箇所に重なる点について、実文書で支障があるかを判断する。支障があれば表示位置を調整する。
- 画像や相対リンクの扱いが実文書で必要かを判断する（PLAN の「相談する事項」）。
